# Acetrix Accounting Website — Outcome Checklist

## Reference-faithful responsive marketing site
- Recreate the supplied Acetrix reference with a premium blue-and-white accounting presentation, clean corporate typography, matching section order, spacing, imagery direction, and responsive behavior.
- Include a reference-matched header with working navigation and a mobile menu.
- Include the hero section, trust strip, all eight accounting services, Why Acetrix, industries, working process, testimonials, FAQ, insights, contact form, and footer.

## Reusable React implementation
- Use reusable React components and shared content data rather than one monolithic page.
- Use React, Vite, and Tailwind CSS with readable, maintainable code.
- Serve the complete page through the project runtime.

## Interactive behavior
- Navigation links scroll to the corresponding sections and the mobile navigation opens/closes cleanly.
- FAQ items expand and collapse with accessible controls.
- The consultation form validates required fields and email format, shows field-level errors, and presents a success state after valid submission.

## Responsive quality
- Make the layout work across desktop, tablet, and mobile breakpoints without horizontal overflow.
- Preserve the reference hierarchy and content density while stacking grids and contact layout appropriately on smaller screens.
- Resolve diagnostics and build/runtime errors before delivery.
